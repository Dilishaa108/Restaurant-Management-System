📚 About This Model

This Iris Species Predictor uses a Random Forest Machine Learning model trained on the famous Iris dataset. The model learns to classify iris flowers into three species based on four physical measurements.

🎯 Iris Species:

  • Setosa - Small flowers with shorter petals (usually 1-2 cm)
  • Versicolor - Medium flowers with medium petals (usually 3-5 cm)
  • Virginica - Larger flowers with longer petals (usually 4-7 cm)

⚙️ Model Algorithm:

  • Algorithm: Random Forest Classifier
  • Training Dataset: UCI Iris Dataset (150 samples)
  • Features: Sepal Length, Sepal Width, Petal Length, Petal Width
  • Accuracy: ~96% on test data

💡 How It Works:

  • The model analyzes relationships between flower measurements
  • Uses ensemble learning (multiple decision trees)
  • Provides confidence scores for each prediction
  • Great introduction to ML classification problems
